# SalesTracker

Petit projet qui a pour but de permettre le suivi des ventes sur un stand. 

![Exemple du mode mobile](screenshot.jpg)

## Feature 

- Authentification via un simple mot de passe (pas de compte utilisateur)
- Chaque périphérique se voit attribuer un nom
- Les ventes sont supprimables (mais reste en mémoire). 
- On peut exporter les ventes en CSV
